# 文档编写规范

按[治理标准](documentation-governance.md)确定职责与状态，再选用[模板](../templates/)。新治理与维护说明以中文为主；已有英文文档无需因迁移而翻译。保留代码标识、协议字段、命令和锚点的原始拼写。站内链接使用相对于所在文档的路径；路径含空格时使用 Markdown 尖括号或 URL 编码，不写本机绝对路径。

| 类型 | 最少说明 |
| --- | --- |
| 标准 | 适用范围、规则、例外和验证方法 |
| 架构 | 当前实现、模块边界、代码入口和不变量 |
| 接口 | 生产方、调用方、认证边界、契约来源及同步要求 |
| 功能 | 当前行为、入口、权限、限制和覆盖证据 |
| 指南 | 前置条件、步骤、预期结果和排障入口 |
| 草案 | 背景、计划、开放问题、未实现或未验证边界 |

规则文档写约束而不是复制实现，操作指南写可运行步骤而不是重新定义规则。当前行为变更时优先更新已有主源；历史测试结果应注明基线，不能作为本次交付的验证结果。
